## Notes

- The FTP data connection uses port 30000, inside the configured passive range 30000-30009. The original project bound passive listeners to a random port on every interface.
- SSH traffic after key exchange is encrypted, so logins and commands are not readable in the capture. The lab records them at the decoy; compare timestamps with the case timelines in `evidence/cases/`.
- HTTP, FTP control, Redis and MySQL are plain text. Use Follow TCP Stream in Wireshark to read them.
- service-sweep only opens a connection to each decoy and closes it, so those streams are a few packets each.
